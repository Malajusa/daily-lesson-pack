# Term 3 Four-Day Overview — Daily Lesson Pack

## Scope

This overview applies to **Monday, Tuesday, Thursday and Friday** in Term 3 Year 4/5 planning. Wednesday remains a valid Daily Lesson Pack day from the authoritative timetable, but it is outside this overview unless the user explicitly requests otherwise.

- Assume the previous scheduled lesson was taught and sufficiently completed unless an explicit user/status exception says otherwise.
- Monday normally follows the preceding Friday; Tuesday follows Monday; Thursday follows Tuesday; Friday follows Thursday.
- HASS is not generated from this overview. A HASS lesson requires a separate authoritative HASS plan or explicit current instruction.
- `term-3-four-day-overview.json` is the deterministic week/day lookup. This Markdown file explains how to use it.

## Mathematics

The weekly mathematics topic and WA code must agree with the Year 4/5 mathematics overview. The four-day overview supplies the **day-level focus** and must not be replaced by a teaching representation such as a number line.

Before generating mathematics resources, confirm the correct term/week/day, weekly topic/code, day focus and continuity. Task slides must not reveal answers; answer slides must model the strategy requested.

## Information Report writing toolkit

Each week has one toolkit component. Use the daily pattern:

- **Monday:** analyse and introduce;
- **Tuesday:** explicitly teach;
- **Thursday:** apply in drafting or revision;
- **Friday:** edit, consolidate or publish.

Every writing lesson must name the toolkit component, teach or apply it explicitly, include a model/worked example when needed, and require a student product demonstrating the component. Country fact collection must not replace writing instruction.

## Country-based reading

Shared Reading and Guided Reading use the countries assigned in the JSON lookup. Any assigned country will be from Europe, Africa, North America or South America.

For each overview-controlled day:

- Shared Reading and Guided Reading must use different countries;
- Morning Work must use a third independent passage or context;
- do not lightly simplify the Shared Reading text for Guided Reading or repeat the same information sequence;
- Shared Reading is a whole-class comprehension/information-text lesson;
- Guided Reading includes a student text, teacher prompts, expected responses, vocabulary support, literal comprehension, inference and an appropriate extended response.

Fixed overview groups:

- Monday: very low;
- Tuesday: low;
- Thursday: above level;
- Friday: approximately Year 9 complexity.

Wednesday retains the normal at-level allocation when guided reading is scheduled, but no overview country is assigned to it.

## Week 1

### Mathematics — Fractions and mixed numerals

- **WA code:** WA5MNAUN6
- **Monday:** Review unit fractions and counting beyond one whole; connect improper fractions and mixed numerals using concrete and visual models.
- **Tuesday:** Locate and represent mixed numerals and improper fractions on number lines.
- **Thursday:** Move flexibly between mixed numerals and improper fractions and explain the equivalence.
- **Friday:** Consolidate representation, conversion and explanation through mixed problems and an exit assessment.

### Writing toolkit — Purpose and audience

- **Monday:** Analyse a model information report to identify its topic, purpose and intended audience.
- **Tuesday:** Explicitly teach how factual language and selected details match the report’s purpose and audience.
- **Thursday:** Apply the focus by revising a short report section for a specified audience.
- **Friday:** Edit a completed section to ensure its purpose and audience are clear.

## Pre-export stop check

Do not release an overview-controlled Term 3 pack if any applicable item fails:

- term/week/day lookup matches the JSON;
- Wednesday has not been treated as part of the overview without an explicit request;
- mathematics topic, WA code and day focus match the overview;
- writing matches the toolkit component and daily stage;
- Shared and Guided Reading countries differ and match the lookup;
- guided-reading level matches the day;
- Morning Work, Shared Reading and Guided Reading are independent;
- no HASS resource has been invented from the overview;
- prior lessons were assumed complete unless an explicit exception exists.
