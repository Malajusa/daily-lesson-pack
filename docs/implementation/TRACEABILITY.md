## Coverage review rule

At the end of each milestone, inspect this mapping alongside the decision ledger. An item must have implementation/evaluation evidence, an explicitly experimental status, or a concrete blocker. A discovered pre-existing implementation can satisfy an issue only after relevant verification; it should not be rewritten solely to match a proposed filename.
