# Regression Examples

Use this directory for compact benchmark cases that verify important Daily Lesson Pack behaviour after skill changes.

Each case should state:

1. **Prompt/context** — what the user asks for.
2. **Behaviour under test** — the skill rule being exercised.
3. **Expected result** — what a successful output must contain or do.
4. **Failure checks** — common errors that would indicate a regression.

## Suggested benchmark categories

- Normal weekday lesson pack
- Monday weekly printing plan and print pack
- Literacy warm-up sequencing and answer slides
- Shared versus guided reading text separation
- Mathematics slide clarity and answer emphasis
- Lesson progression from the previous school day
- Curriculum-authority checks
- Relief-cover variant
- Printable-backup requirements
- Output-format and file-generation requirements

Do not treat an old generated pack as authoritative where later skill decisions have deliberately changed the expected behaviour.
