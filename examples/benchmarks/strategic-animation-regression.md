# Strategic-animation regression

Use the active year profile and existing concept-family benchmarks. These cases
test instructional sequencing and format evidence, not measured classroom impact.
Run in a clean context without conversation memory or an sshow dependency.

## Addition strategy model

Prompt: Create a compensation-for-addition teaching model using `59 + 29`, then
provide an unresolved comparable task and its matched answer. Use strategic
animations to support processing and teacher questioning.

Require one readable native model slide, original problem visible on entry,
three useful on-click stages, an extra unit added then removed, persistent prior
working, and an unresolved task followed by its answer. Do not apply the model's
three-click count to all future examples. Independently check each sum and each
visible counter quantity.

Fail: four near-identical slides with Fade presented as Appear; solution visible
on entry; changing the wrong quantity; removing the whole counter model;
automatic advance; numerous clicks for individual counters; unlabelled fallback;
claiming PowerPoint playback from XML or simulated screenshots.

## Fraction equivalence

Prompt: Show how `1/2 = 2/4` using one precisely divided whole, with opportunities
to predict and explain, then give an independent transfer item.

Require the whole and shaded amount to remain invariant, each half to be divided
equally, the changed partition and matching notation to be revealed together,
prior evidence to remain inspectable, and a stable final model. Choose useful
steps rather than forcing the addition example's three clicks.

Fail: whole size changes; only the shaded half is repartitioned; moving objects
implies unequal quarters; colour alone carries meaning; independent work exposes
the method; correct final equation conceals an invalid intermediate state.

## Component boundaries and exports

- A Numeracy warm-up retains its authorised pair count and immediate matched
  question/answer adjacency; optional feedback staging belongs on the answer.
- Shared Reading retains paragraph/question then matched answer. Animation does
  not replace that pair or reveal teaching-only evidence on the question slide.
- A writing comparison keeps the original proposition visible while one feature
  is annotated/revised; no word-by-word movement or unacknowledged fact deletion.
- With no native animation capability, return the limitation and an accurately
  labelled candidate/plan; do not silently duplicate slides or depend on sshow.
- Inspect flattened student PDFs for answer leakage and teacher views for
  overlapping before/after objects. Keep existing printable content bindings.
- Validate final exported timing; a tool which strips it fails the native-effects
  check even when its pre-export preview looked correct.
- Without actual host playback, report that check as unverified, never PASS.

## Migration and rollback

Existing static decks need no retrofit merely because this standard is installed.
Apply the rule during creation or authorised revision. Keep existing pairs and
content ownership. Any edited deck needs fresh final-file evidence.
Rollback this source change and republish the previous plugin release if needed;
do not reuse old release evidence against files with changed hashes.
