# T3W7 Thursday known-failure regression

This regression records the defects that passed the 3.5.0 release gates. It is
not an approved classroom exemplar.

## Required rejection cases

A candidate reproducing any of these conditions must fail release:

- ten Numeracy prompt/answer pairs when the active profile requires five;
- two scheduled Mathematics blocks represented by one undifferentiated instance;
- an instance whose estimated teaching time exceeds its timetable allocation;
- generic component `PASS` strings without stable check IDs and cited evidence;
- mixed Year 4/5 instruction with no explicit pathway for each year level;
- a final hundred grid presented as the explanation of fraction equivalence,
  without showing repartitioning and the invariant amount;
- projected mathematical fractions typed with a forward slash where stacked
  notation is practical;
- any meaningful warm-up task text below 36 pt, even if another element on the
  same slide reaches 36 pt;
- unresolved typography or space-use warnings dismissed as a batch;
- visual-exemplar screening reported as final visual approval without an
  independent rendered-review record;
- a generated one-off release script containing expected slide counts or exact
  answer strings for the current deck.

## Required passing comparison

A corrected Thursday record contains distinct `maths-1` and `maths-2`
instances, five Numeracy pairs, time estimates within both Mathematics blocks,
evidence-bearing checks, explicit Year 4 and Year 5 pathways, and a fraction
model that visibly repartitions the same whole. All automated reports must be
generated by repository-owned scripts. Every warning must be resolved or have
a specific documented disposition tied to the audited artefact hash.
