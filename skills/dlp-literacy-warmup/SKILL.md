# DLP Literacy Warm-up

## Ownership

Own the Literacy warm-up only. Keep it separate from Morning Work, Shared Reading, Guided Reading, spelling instruction and the main writing lesson.

## Length and sequence

Create exactly **10 prompt-and-answer pairs** (20 slides) unless the user explicitly changes the count. Each answer immediately follows its prompt.

Each prompt should usually take about 20–45 seconds and produce visible student thinking or writing.

## Content

Use high-leverage literacy retrieval and language work such as:
- vocabulary and morphology for meaning;
- punctuation;
- sentence construction and improvement;
- parts of speech where useful;
- cohesion and reference;
- fact/opinion/evidence;
- text-feature recognition;
- information-report language and structure.

Do not turn morphology into a Sound Waves-style spelling drill. Exclude spelling lists, phonics, grapheme/sound drills, dictated words and Sound Waves replacement content.

## Difficulty

Questions must be student-friendly and pitched so an average Year 4/5 student can understand what to do immediately. Increase thinking demand through the sequence without using unnecessarily adult or abstract wording.

## Answer slides

- Put the complete primary answer in bold, visually dominant text.
- Add a short explanation only when it improves learning.
- Do not shrink meaningful explanations into fine print.

## Presentation

- Use Trebuchet MS for the established warm-up system.
- Main question/answer content is normally at least 36 pt and should grow when space allows.
- Use the largest sensible type rather than preserving empty decorative space.
- No generic footer telling students to use whiteboards; that routine is already known.

## QA

Fail if any prompt is ambiguous, if spelling instruction has crept in, if an answer does not immediately follow its question, if the primary answer is not visually dominant, or if content is undersized despite available space.
