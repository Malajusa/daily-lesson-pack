# DLP Guided Reading

## Ownership

Own Guided Reading only. It is targeted small-group instruction, not a second Shared Reading lesson.

## Day/group defaults

When the active plan schedules Guided Reading, use the established weekday allocation unless explicitly overridden:
- Monday: very low group;
- Tuesday: low group;
- Wednesday: at-level group;
- Thursday: above-level group;
- Friday: approximately Year 9 text complexity.

On overview-controlled days, use the assigned Guided Reading country and keep it different from Shared Reading.

## Required outputs

Produce:
- a student text pitched to the scheduled group;
- vocabulary support appropriate to that group;
- teacher prompts;
- expected responses;
- literal comprehension;
- at least one supported inference where appropriate;
- an appropriate oral or written extended response.

The teacher guide must match the student text exactly.

## Independence

If the guided conference occurs during a one-hour Literacy block, the rest of the class needs a genuinely independent task. Do not assume the teacher can run two simultaneous teacher-dependent activities.

## QA

Fail if the text difficulty does not match the scheduled group, if teacher questions refer to unavailable information, if the same text is used for Shared Reading, or if the guide and student text do not match.
